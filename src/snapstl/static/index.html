SnapSTL Helper (Chrome)

Models are generated in your normal Chrome, where you're signed in to MakerWorld. The helper fills the model-maker page for each queued name, presses Generate and hands the files to SnapSTL. Security checks: just click them in that tab.

  1. Download the helper and unzip it (or use the helper folder in the SnapSTL project).
  2. Chrome → chrome://extensions → turn on Developer mode → Load unpacked → pick the folder.
  3. Open the MakerWorld model maker in Chrome and leave that tab open. That's it — no codes or settings.
