SnapSTL Helper (Chrome)

Models are generated in your normal Chrome, where you're signed in to MakerWorld. The helper fills the model-maker page for each queued name, presses Generate and hands the files to SnapSTL. Security checks: just click them in that tab.

  1. Download the helper and unzip it (or use the helper folder in the SnapSTL project).
  2. Chrome → chrome://extensions → turn on Developer mode → Load unpacked → pick the folder.
  3. Open the MakerWorld model maker in Chrome and leave that tab open. That's it — no codes or settings.

SnapSTL turns webstore orders for the Custom Name Desk Organizer (SKU Magicians_35) into print-ready plates: each name is generated on MakerWorld, scaled to the agreed rules, grouped 3 per plate and saved as .3mf files.

Daily workflow

  1. Orders → Upload report (.xlsx) — the webstore Order Reconciliation Report. Only Magicians_35 orders are kept. Uploading the same or a newer report never creates duplicates; it only updates statuses.
  2. Needs review — fix names with spaces, symbols or missing colour, then Approve. Use Skip for orders you don't want to make.
  3. Ready — tick orders (or use the column filters and Select all matching) → Create batch.
  4. Batches → Start download — the helper in your MakerWorld tab generates each name, one at a time.
  5. When the batch says Ready to build → Build plates.
  6. Show in Finder, open the plates in Bambu Studio, check, slice and print. Bases in white; names in the colour of their folder.

The SnapSTL Helper (Chrome)

The helper is a small Chrome extension that does the MakerWorld part in your normal Chrome, where you're signed in. For each name it fills the model-maker page (NO AMS, the name, compartments from the scaling table, your font settings), presses Generate and sends the two files to SnapSTL.

  • Install once: chrome://extensions → Developer mode → Load unpacked → the helper folder (or download it from Settings).
  • Keep the MakerWorld model-maker tab open, ideally in its own window — Chrome slows down hidden tabs.
  • If MakerWorld shows a security check in that tab, complete it; the helper waits and carries on.
  • The sidebar shows the helper's status. Pause downloads stops it after the current name.

Each .3mf is one plate; every base or name is its own named object in Bambu Studio, already placed on the 256 × 256 mm bed. Names: one colour per plate, up to 3. Bases: 3 per plate (the last plate may have fewer). No ZIP files are created.

Fit & scaling

Every organizer is resized to a target length and height by letter count (Settings → Scaling). The name piece always gets exactly the same length and height factors as its base (Name X = Base X, Name Y = Base Z; thickness 50 %), so it keeps MakerWorld's proportions and fits the base after printing.

Fit check: for every order SnapSTL checks that the name's size relative to its base (length % and height %) is unchanged — once after scaling and again by measuring the .3mf files it wrote. A pair that fails is not printed: it's left out of the plates and its order returns to Ready. The batch page shows "Fit check: N/N", and report.csv lists name_vs_base_length_%, name_vs_base_height_% and fit_check per order.

A name and its base are always built in the same batch with the same settings — don't print a name from one batch with a base from another after changing scaling settings.

Settings

  • Model maker options — font, font size, thickness, outline, rotate text; same for every name. Changing them makes new models (old ones stay cached).
  • MakerWorld license password — removes the anti-sale markings; stored in the Mac Keychain.
  • Scaling and compartments — target length/height and compartments per letter count (Scaling Rules v1.1).
  • Plate and fit — bed size, edge margin, gap between parts, names/bases per plate, allowed rotations (flat on the bed only).
  • Output folder — where dated batch folders go. Pause between downloads — seconds between names.
  • Database — back up, clean up old records (orders already made are always kept), or reset.

Your data

Everything stays on this Mac. Orders database, model cache, settings and backups: ~/Library/Application Support/SnapSTL. Output: your chosen output folder. Customer names, phones and addresses are only stored in the local database. SnapSTL runs in the background (it starts at login); the window is just a view — you can also open http://127.0.0.1:8317 in a browser.
